# Appendix Cutoff Panels

This figure family contains support-only composite setup/support panels for the five rolling-origin cutoffs used in the revised article workflow. They are retained for review and provenance, but the manuscript appendix now uses the cutoff-specific multivariate synthesis overlay figures.

Each panel contains four subplots for one cutoff:
- USGS observations to cutoff
- PPT/SOIL/GDPC histories to cutoff
- retrospective support used by fit
- forecast-product context over the short forecast review window
