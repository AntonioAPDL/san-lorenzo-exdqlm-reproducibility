# HE-7 Latest Forecast Issue Artifact

This directory contains the compact machine-readable contract for the
latest-forecast-only protocol used by the revised article and corrections
response.

The manifest records that publication forecast matrices use the latest
forecast issue available at each cutoff and do not average older issuances.
It also records that legacy `weighted_daily` file names are compatibility
aliases for latest-issue member matrices.

Authoritative manifest:

- `latest_forecast_issue_manifest.json`
